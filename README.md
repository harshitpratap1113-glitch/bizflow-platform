## 🌟 Overview

**BizFlow AI** is an all-in-one client acquisition and automated lead pipeline platform built for agency owners, SaaS founders, and sales development teams. It replaces manual LinkedIn & cold database prospecting with an automated **Tri-Box LeadRadar** architecture that identifies high-value decision-makers, validates their deliverability, and drafts high-converting outbound copy in seconds.

---

## ✨ Key Features

- 🎯 **Tri-Box LeadRadar Engine**: Concurrent discovery across 3 high-intent verticals:
  1. *Early-Stage & Funded Tech Startups*
  2. *High-Growth Digital & Creative Agencies*
  3. *SMBs & Service Providers Scaling Online Operations*
- 🔍 **Deep Lead Intelligence**: Extracts verified business domains, founder email patterns, LinkedIn URLs, tech stack insights, and estimated deal value.
- ⚡ **Automated Outbound Sequences**: AI-generated cold pitch templates tailored to each prospect's niche, pain points, and current tech stack.
- 🛡️ **Anti-Bounce Verification**: Pre-checks domain MX records and mailbox hygiene before queuing outreach.
- 📊 **Real-Time Pipeline Analytics**: Track sent emails, open rates, response triggers, and pipeline revenue from a unified dark-mode dashboard.
- 📁 **Instant Export**: 1-click export to clean CSV, JSON, or direct webhook sync.

---

## 🛠️ Architecture & Tech Stack

- **Frontend**: Clean Vanilla JavaScript (ES6+), Modern Semantic HTML5, Glassmorphism UI with Tailwind CSS palette.
- **Backend / Deployment**: Vercel Serverless Edge, Node.js API handlers, automated Python dispatch engines.
- **Outbound Infrastructure**: Google SMTP Relay, Resend Cloud API, Brevo Mail Gateway.
- **Telemetry**: Real-time traffic analytics via [TrafficPulse AI](https://trafficpulse-platform.vercel.app).

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/harshitpratap1113-glitch/bizflow-platform.git
cd bizflow-platform
```

### 2. Run locally with any static server or Python
```bash
# Using Python
python -m http.server 3000

# Or using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
